# AI Security Lab

Yerel eğitim GUI'si: encoding lab, prompt injection simülatörü, attack library, OWASP checklist, quiz.

ChatGPT'ye saldırmez. Kendi makinede, eğitim amaçlı.

## Çalıştır

```bash
pip install -r requirements.txt
python main.py
```

Windows EXE (PyInstaller) ayrı paketlenir.

## Ne var

- Encoding Lab (Base64, hex, ROT13, Morse, Unicode)
- Prompt injection senaryoları
- Attack library (payload arşivi)
- OWASP-tarzı checklist + training mode

Kaynak: yerel Windows GUI (CustomTkinter).
